# Документация

Документация по проектной (учебной) практике в связке с проектом «Telegram-бот оповещений о расписании Московского политеха».

## Проект

Telegram-бот для просмотра расписания Московского политеха и напоминаний перед занятиями. API: [rasp.dmami.ru](https://rasp.dmami.ru/), библиотека mospolytech_api. Исходный код бота — в каталоге `src/`.

## Этапы

1. Git и репозиторий на GitHub.
2. Документация в Markdown (`docs/`).
3. Статический сайт (`site/`) — см. [practice_documentation.md](practice_documentation.md).
4. Отчёт DOCX/PDF в `reports/`.
5. Загрузка отчёта в СДО.

## Git

`git clone`, `git add`, `git commit`, `git push`, ветки. В `.gitignore`: `.env`, `bot_data.db`, файлы IDE.
