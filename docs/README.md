# Документация по проектной (учебной) практике

Журнал выполнения практики в связке с проектом по дисциплине «Проектная деятельность»: **Telegram-бот оповещений о расписании Московского политеха**.

## Цель практики

Освоить работу с Git и Markdown, создать статический сайт о проекте ПД и подготовить отчётную документацию.

## Связь с проектной деятельностью

| Практика | Проект ПД |
|----------|-----------|
| Сайт, `docs/`, отчёт | Рабочий Telegram-бот |
| Папка `practice/` | Исходный код в корне репозитория (`../`) |

Бот решает задачу быстрого доступа к расписанию и напоминаний перед парами. Сайт описывает проект для преподавателей и пользователей.

## Этапы работы

| Этап | Содержание | Статус |
|------|------------|--------|
| 1 | Репозиторий, структура папок по [шаблону](https://github.com/mospol/practice-2025-1) | выполнено |
| 2 | Документация в `docs/` | выполнено |
| 3 | Статический сайт в `site/` | выполнено |
| 4 | Отчёт DOCX/PDF в `reports/` | _заполнить_ |
| 5 | Загрузка отчёта в СДО | _заполнить_ |

## Ход работы (краткий журнал)

### Этап 1 — Репозиторий и Git

- Создан репозиторий на GitHub.
- Настроен `.gitignore` (исключены `.env`, `.venv`, служебные файлы IDE).
- Материалы практики вынесены в папку `practice/`, код бота — отдельно.

Подробнее: [git-workflow.md](git-workflow.md).

### Этап 2 — Markdown-документация

- Оформлены `docs/README.md` и сопутствующие файлы.
- Описаны этапы практики и связь с проектом ПД.

### Этап 3 — Статический сайт

- Сверстаны страницы: главная, о проекте, участники, журнал, ресурсы.
- Использованы HTML и CSS (`site/css/style.css`).
- Добавлены схема архитектуры бота и места под скриншоты.

### Этап 4 — Отчёт

- Подготовка по шаблону `practice_report_template.docx` (кафедра).
- Акцент: **создание сайта и работа с Git**, не разработка бота.
