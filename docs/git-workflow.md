# Работа с Git (для отчёта по практике)

Краткое описание шагов, которые можно сопроводить скриншотами в отчёте.

## 1. Создание репозитория

- Репозиторий на GitHub (или GitVerse).
- При необходимости — форк шаблона [mospol/practice-2025-1](https://github.com/mospol/practice-2025-1) с последующим добавлением папки `practice/`.

## 2. Клонирование

```bash
git clone https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
cd ВАШ_РЕПОЗИТОРИЙ
```

## 3. Добавление материалов практики

```bash
git add practice/
git status
git commit -m "Добавлены материалы проектной практики: site, docs, reports"
```

**Важно:** не добавлять в коммит `.env`, `.venv`, `.vs/`, `bot_data.db`.

## 4. Отправка на GitHub

```bash
git push origin main
```

(или `master` — в зависимости от имени ветки по умолчанию.)

## 5. Ветки (по заданию)

Пример работы с веткой:

```bash
git checkout -b practice-site
# правки в site/
git add practice/site/
git commit -m "Обновление страницы журнала"
git push -u origin practice-site
```

## 6. Осмысленные сообщения коммитов

Примеры:

- `docs: журнал практики, этап 3`
- `site: страницы о проекте и ресурсы`
- `practice: структура репозитория по заданию`

## Доступ преподавателям

Выдайте доступ на чтение (или write) ответственному за практику и куратору ПД — по инструкции кафедры.
