# Документация статического сайта

Сайт расположен в `site/`. Технологии: HTML5, CSS3.

## Структура

```
site/
├── index.html
├── about.html
├── team.html
├── journal.html
├── resources.html
├── css/style.css
└── images/
    ├── architecture.svg
    └── *.jpg
```

## Страницы

| Файл | Назначение |
|------|------------|
| index.html | Главная, аннотация проекта |
| about.html | О проекте, схема, скриншоты бота |
| team.html | Участники и вклад в проект |
| journal.html | Журнал прогресса |
| resources.html | Ссылки на материалы |

## Навигация

На всех страницах: Главная, О проекте, Участники, Журнал, Ресурсы.

## Медиа

- `images/architecture.svg` — схема работы бота
- скриншоты интерфейса PolyNotify на странице «О проекте»
