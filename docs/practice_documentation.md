# Документация статического сайта

Сайт расположен в `practice/site/`. Технологии: **HTML5**, **CSS3** (без фреймворков).

## Структура файлов

```
site/
├── index.html      — главная (аннотация)
├── about.html      — о проекте ПД
├── team.html       — участники
├── journal.html    — журнал (≥ 3 записи)
├── resources.html  — ссылки
├── css/
│   └── style.css
└── images/
    └── architecture.svg — схема работы бота
```

## Страницы и соответствие заданию

| Требование задания | Страница |
|--------------------|----------|
| Домашняя с аннотацией | `index.html` |
| О проекте | `about.html` |
| Участники, вклад | `team.html` |
| Журнал, ≥ 3 поста | `journal.html` |
| Ресурсы | `resources.html` |

## Навигация

Общее меню на всех страницах: Главная, О проекте, Участники, Журнал, Ресурсы.

## Медиа

- Схема: `images/architecture.svg`
- Рекомендуется добавить скриншоты бота в `images/` и вставить на `about.html` или `journal.html` (замените блоки-заглушки).

## Просмотр локально

Откройте `site/index.html` двойным щелчком или через Live Server в VS Code.

## Публикация

Материалы лежат в репозитории; при необходимости — [GitHub Pages](https://pages.github.com/) из ветки `gh-pages` или папки `/docs` (по согласованию с преподавателем).
