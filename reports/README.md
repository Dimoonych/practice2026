# Отчёты по практике

Разместите здесь:

| Файл | Описание |
|------|----------|
| `Отчёт.docx` или `report.docx` | Отчёт по шаблону кафедры |
| `report.pdf` | PDF-версия того же отчёта |

## Содержание отчёта (ориентир, до ~10 страниц)

По указанию преподавателя — **описание по шагам работы по созданию сайта и работе с GitHub**, а не подробный разбор кода бота.

Рекомендуемая структура:

1. Титульный лист (по шаблону)  
2. Введение — цель практики, связь с проектом ПД  
3. Настройка Git и репозитория (скриншоты)  
4. Документация в Markdown (`docs/`)  
5. Создание статического сайта — структура, страницы, стили  
6. Размещение материалов на GitHub  
7. Заключение  

Код Telegram-бота — кратко в приложении или 1–2 абзаца со ссылкой на репозиторий с исходниками.

После подготовки загрузите **оба** файла в СДО (LMS).
